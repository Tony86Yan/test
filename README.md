# Northlea School Evaluation Project

This repository contains a comprehensive evaluation of **Northlea Elementary and Middle School**, a JK-8 public school in Toronto's Leaside neighborhood.

## Contents

- **northlea_school_evaluation.md** - Complete school evaluation report including:
  - Academic performance assessment
  - Programs and enrichment opportunities
  - Facilities and resources review
  - School culture and environment
  - Teaching staff evaluation
  - Community feedback
  - Overall ratings and recommendations

## Evaluation Overview

**Overall Rating: ⭐⭐⭐⭐ (4.2/5)**

Northlea Elementary and Middle School is evaluated as a high-quality public school that excels in:
- Academic achievement
- Comprehensive programming
- Strong community engagement
- Inclusive and supportive environment
- Excellent location in family-friendly Leaside

## How to Use This Evaluation

This evaluation is designed for:
- **Prospective families** considering Northlea School
- **Current families** wanting to understand the school's strengths
- **Educational researchers** studying Toronto schools
- **Community members** interested in local education quality

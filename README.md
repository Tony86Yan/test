# 时间序列趋势识别方法

本项目提供了一套完整的时间序列数据趋势识别解决方案，支持识别线性和非线性趋势，并量化趋势的方向（上升/下降/平稳）和程度（强/中等/弱）。

## 📊 功能特性

- **7种趋势识别方法**：从简单到复杂，从参数到非参数
- **线性和非线性趋势**：适用于各种趋势模式
- **趋势量化**：不仅识别方向，还量化强度
- **综合分析**：多方法投票，提高结果可靠性
- **开箱即用**：完整示例代码和详细文档

## 🚀 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 基本使用

```python
from timeseries_trend_analysis import TimeSeriesTrendAnalyzer
import pandas as pd

# 准备数据（date, amount格式）
dates = ['2023-01-01', '2023-01-02', '2023-01-03', ...]
amounts = [100, 105, 103, ...]

# 创建分析器
analyzer = TimeSeriesTrendAnalyzer(dates, amounts)

# 综合分析（推荐）
result = analyzer.comprehensive_analysis()

print(f"趋势: {result['consensus_trend']}")
print(f"程度: {result['consensus_degree']}")
print(f"置信度: {result['confidence']:.1f}%")
```

## 📚 支持的方法

| 方法 | 适用场景 | 优势 |
|------|---------|------|
| **线性回归** | 线性趋势 | 简单直观，计算快速 |
| **Mann-Kendall检验** | 单调趋势，有异常值 | 非参数，鲁棒性强 |
| **多项式回归** | 非线性趋势 | 捕捉曲线特征 |
| **移动平均斜率** | 噪声数据 | 平滑处理效果好 |
| **Spearman相关** | 单调关系，异常值 | 基于排名，抗异常值 |
| **去趋势波动分析** | 长期趋势 | 区分趋势和波动 |
| **变点检测** | 趋势转折 | 识别结构变化 |

## 💡 使用建议

1. **首选综合分析**：`comprehensive_analysis()` 使用多方法投票，结果更可靠
2. **数据预处理**：确保至少20个数据点，处理缺失值和异常值
3. **可视化验证**：结合图表验证分析结果
4. **结合业务知识**：统计结果需要业务背景的解释

## 🔧 方法选择指南

| 数据特征 | 推荐方法 |
|---------|---------|
| 线性趋势 | 线性回归、Mann-Kendall |
| 非线性趋势 | 多项式回归、Spearman相关 |
| 有异常值 | Mann-Kendall、Spearman相关 |
| 噪声大 | 移动平均斜率、多项式回归 |
| 有转折点 | 变点检测 |
| 不确定 | 综合分析（推荐） |
